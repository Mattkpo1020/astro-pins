# Astro Pins

Alfa web 0.18.1: 200 pins astronómicos, sobres, álbum, metas, cosméticos y dados. Incluye ambient espacial, efectos y volúmenes separados, cinco sobres premium, categoría en la apertura e inclinación opcional del pin.

## Jugar

Abrí [Astro Pins](https://mattkpo1020.github.io/astro-pins/) con conexión y esperá «Listo sin conexión». En iPhone: Safari → Compartir → Agregar a Inicio, con «Abrir como app web» activado. Cada dispositivo conserva su propia partida local; no hace falta cuenta de GitHub.

Para actualizar: abrir con conexión, esperar la descarga, cerrar todas las ventanas de Astro Pins (Safari y app de Inicio) y volver a abrir. Comprobar «Alfa 0.18.1» antes de jugar. No borrar la app ni los datos del navegador. Las partidas de otro dominio requieren respaldo/importación desde Ajustes → Partida.

En Ajustes → Juego se controlan efectos, música, movimiento reducido e inclinación del teléfono. La inclinación necesita permiso del navegador en iPhone y conserva el arrastre manual. El sensor físico debe validarse en el teléfono; en Windows indica no disponible. Safari no ofrece vibración web. Al girar el móvil se muestra el aviso para volver a vertical. Hay una entrada opcional sin sonido.
